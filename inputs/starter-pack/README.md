# `claims-api` onboarding starter pack

This is a synthetic customer request and platform contract. It intentionally leaves
some decisions open; the candidate should document assumptions rather than silently
inventing platform behavior.

## Files

- `application-notes.md`: customer-owned application facts
- `platform-contract.md`: capabilities and boundaries the integration must respect
- `customer-request.md`: the original request as received

The candidate may add files and choose a different layout, but the original inputs
should remain unchanged in the submission.
